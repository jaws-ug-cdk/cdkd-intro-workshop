## 症状

ログインはできているのに、`cdkd bootstrap` や `cdkd deploy`、`cdk deploy` で `AccessDenied` や `403 Forbidden` のエラーになります。

## 原因

会社などの組織で管理されている AWS アカウントでは、組織のルールで次のような制限がかかっていることがあります。

- 決められたネットワーク（社内ネットワークなど）以外からの操作を禁止している
- S3 バケットや IAM ロールの作成など、特定の操作を禁止している

GitHub Codespaces は GitHub のクラウド上で動いているので、社内ネットワークからの操作とはみなされません。手元のパソコンでは使える AWS アカウントでも、Codespaces からはエラーになることがあります。

## 対処法

組織の制限は、ワークショップの中では解除できません。個人で作った AWS アカウントを使ってください（[事前準備]({{< ref "/" >}})を参照）。
