## 症状

`cdkd` のコマンドを実行すると、次のようなエラーになります。

```
bash: cdkd: command not found
```

## 対処法

cdkd がインストールされていません。[cdkd をインストールする]({{< ref "/20-getting-started/200-install-cdkd" >}})の手順でインストールしてください。

Codespace を作り直した場合も、cdkd をもう一度インストールする必要があります。
