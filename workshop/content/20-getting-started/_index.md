# 環境準備

3 つの方法でデプロイするための環境を準備します。

1. AWS にログインする
2. cdkd をインストールする
3. CDK と cdkd の bootstrap を行う

{{% notice warning %}}
**AWS 利用料についての免責事項**: この後の手順では課金対象のリソースを作成します。
サーバーレスのリソースを扱うため基本的にほとんど料金はかかりませんが、発生した費用についてはこちらでは負担できませんのでご了承ください。
{{% /notice %}}
