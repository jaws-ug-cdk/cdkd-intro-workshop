## 手順

cdkd は npm のパッケージとして公開されています。次のコマンドで、Codespace に cdkd をインストールします。

```bash
npm i -g @go-to-k/cdkd@0.296.25
```

インストールには 1 分ほどかかります。

{{% notice info %}}
**`npm i -g` とは**: npm は Node.js のパッケージを管理するツールです。`-g`（グローバル）を付けると、どのディレクトリからでも `cdkd` というコマンドで使えるようにインストールされます。`@0.296.25` の部分は、インストールするバージョンを指定しています。
{{% /notice %}}

## 確認

次のコマンドを実行します。

```bash
cdkd --version
```

インストールしたバージョンが表示されれば完了です。

```
0.296.25
```

{{% notice note %}}
CDK の CLI（`cdk` コマンド）は、Codespace の起動時に `code` ディレクトリのパッケージとしてインストール済みです。こちらは `npx cdk` のように `npx` を付けて実行します。
{{% /notice %}}
